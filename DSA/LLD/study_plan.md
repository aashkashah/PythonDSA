1. Python OOP — 2–3 days
Coming from C#, focus only on differences that matter:
    Learn:
    - __init__
    - instance vs class attributes
    - @classmethod, @staticmethod
    - inheritance
    - composition
    - abc / abstract classes
    - Protocol
    - dataclass
    - properties
    - enums
    - type hints
    - Python collections

2. Design principles — 2–3 days
Translate what you already know from C#:
- SOLID
- composition vs inheritance
- dependency inversion
- interfaces/abstractions
- strategy pattern
- factory
- observer
- state
- repository
- dependency injection

3. Small designs — ~1 week
Start with very small problems:
1. Parking lot
2. Library management
3. Coffee machine
4. Elevator
5. Tic-tac-toe
6. Vending machine
7. Notification system
8. Payment processing
For each one, practice the same sequence:
Requirements → entities → relationships → interfaces → core methods → edge cases

Don't spend 2 hours coding.
Aim for 30–45 minutes.

4. Interview simulation
Eventually give yourself 45 minutes:
"Design a notification system."
